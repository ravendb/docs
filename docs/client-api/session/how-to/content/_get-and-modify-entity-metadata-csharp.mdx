<Admonition type="note" title="">

* When you load a document from the server, the session also stores the document's metadata, like the document's ID and
  current change vector.  
  To get or modify the metadata of an entity, use the `GetMetadataFor` method of the session's `Advanced` operations.

* In this article:
   * [Get the metadata](../../../../client-api/session/how-to/get-and-modify-entity-metadata.mdx#get-the-metadata)
   * [Modify the metadata](../../../../client-api/session/how-to/get-and-modify-entity-metadata.mdx#modify-the-metadata)
   * [Syntax](../../../../client-api/session/how-to/get-and-modify-entity-metadata.mdx#syntax)

</Admonition>

<Panel heading="Get the metadata">

To get an entity's metadata, pass the entity to `session.Advanced.GetMetadataFor`.  
The session must track the entity: load or store the entity using the session before getting the entity's metadata.  
e.g., the following code loads an `Employee` document and gets the document's metadata.

```csharp
var employee = session.Load<Employee>("employees/1-A");
var metadata = session.Advanced.GetMetadataFor(employee);
```

</Panel>

<Panel heading="Modify the metadata">

`session.Advanced.GetMetadataFor` returns the metadata as a dictionary.  
To add a metadata property, set a value for a new key.  
To change an existing metadata property, set a new value for the property's key.  
The change will be saved to the database as part of the document when you call `SaveChanges`.

<Admonition type="note" title="">
Metadata keys that start with `@` are reserved for RavenDB use.
</Admonition>

<ContentFrame>

### Example: Adding metadata to a new entity

The following code stores a new `User` document, adds a `Permissions` property to the document's metadata, and saves the
document.

```csharp
var user = new User
{
    Name = "Idan"
};

session.Store(user);
var metadata = session.Advanced.GetMetadataFor(user);
metadata["Permissions"] = "ReadOnly";
session.SaveChanges();
```

</ContentFrame>

<ContentFrame>

### Example: Modifying the metadata of a loaded entity

The following code loads a `User` document, sets the `Permissions` property of the document's metadata, and saves the
change.

```csharp
var user = session.Load<User>("users/1-A");
var metadata = session.Advanced.GetMetadataFor(user);

metadata["Permissions"] = "ReadAndWrite";

session.SaveChanges();
```

</ContentFrame>

</Panel>

<Panel heading="Syntax">

```csharp
IMetadataDictionary GetMetadataFor<T>(T instance);
```
<br />

| Parameter | Type | Description |
|-----------|------|-------------|
| **instance** | `T` | The entity whose metadata to get. The session must track the entity. |

| Return value | |
|--------------|-|
| `IMetadataDictionary` | The entity's metadata.<br />If the session does not track the entity, the method throws an exception. |

</Panel>
