<Admonition type="note" title="">

* Use method `where_exists()` to query for documents that contain a particular field.  
  A document that doesn't contain the specified field will be excluded from the query results.

* `where_exists()` filters documents by field presence, not by how relevant the field's value is.  
  When you [order results by score](../../../../querying/sorting-query-results/sort-query-results.mdx#order-by-score), `where_exists()` can contribute to that score.  
  For how this contribution works with Corax, see [Corax: Scoring](../../../../indexes/search-engine/corax.mdx#scoring).  

* In this article:  
  * [Filter by field name](#filter-by-field-name)  
  * [Filter by field path](#filter-by-field-path)  
  * [Syntax](#syntax)

</Admonition>

<Panel heading="Filter by field name">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
```python
# Only documents that contain field 'first_name' will be returned
    
results = list(session.advanced.document_query(object_type=Employee).where_exists("first_name"))
```
</TabItem>
<TabItem value="RQL" label="RQL">
```sql
// Only documents that contain the 'FirstName' field will be returned

from Employees
where exists("FirstName")
```
</TabItem>
</Tabs>

</Panel>

<Panel heading="Filter by field path">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
```python
# Only documents that contain the 'latitude' property in the specified path will be returned
    
results = list(
    session.advanced.document_query(object_type=Employee).where_exists("address.location.latitude")
)
```
</TabItem>
<TabItem value="RQL" label="RQL">
```sql
// Only documents that contain the 'Latitude' property in the specified path will be returned

from Employees
where exists("Address.Location.Latitude")
```
</TabItem>
</Tabs>

</Panel>

<Panel heading="Syntax">

```python
def where_exists(self, field_name: str) -> DocumentQuery[_T]: ...
```
<br/>

| Parameter      | Type  | Description                                        |
|----------------|-------|----------------------------------------------------|
| **field_name** | `str` | The name / path of the document field to filter by |
