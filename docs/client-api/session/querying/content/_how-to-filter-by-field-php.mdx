<Admonition type="note" title="">

* Use method `whereExists()` to query for documents that contain a particular field.  
  A document that doesn't contain the specified field will be excluded from the query results.

* `whereExists()` filters documents by field presence, not by how relevant the field's value is.  
  When you [order results by score](../../../../querying/sorting-query-results/sort-query-results.mdx#order-by-score), `whereExists()` can contribute to that score.  
  For how this contribution works with Corax, see [Corax: Scoring](../../../../indexes/search-engine/corax.mdx#scoring).  

* In this article:  
  * [Filter by field name](#filter-by-field-name)  
  * [Filter by field path](#filter-by-field-path)  
  * [Syntax](#syntax)

</Admonition>

<Panel heading="Filter by field name">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
```php
// Only documents that contain field 'FirstName' will be returned

/** @var array<Employee> $results */
$results = $session
    ->advanced()
    ->documentQuery(Employee::class)
    ->whereExists("FirstName")
    ->toList();
```
</TabItem>
<TabItem value="RQL" label="RQL">
```sql
// Only documents that contain field 'FirstName' will be returned

from Employees
where exists("FirstName")
```
</TabItem>
</Tabs>

</Panel>

<Panel heading="Filter by field path">

<Tabs groupId='languageSyntax'>
<TabItem value="Query" label="Query">
```php
// Only documents that contain the 'Latitude' property in the specified path will be returned

$results = $session
    ->advanced()
    ->documentQuery(Employee::class)
    ->whereExists("Address.Location.Latitude")
    ->toList();
```
</TabItem>
<TabItem value="RQL" label="RQL">
```sql
// Only documents that contain the 'Latitude' property in the specified path will be returned

from Employees
where exists("Address.Location.Latitude")
```
</TabItem>
</Tabs>

</Panel>

<Panel heading="Syntax">

```php
public function whereExists(?string $fieldName): DocumentQueryInterface;
```
<br/>

| Parameter      | Type      | Description                                        |
|----------------|-----------|----------------------------------------------------|
| **$fieldName** | `?string` | The name / path of the document field to filter by |
