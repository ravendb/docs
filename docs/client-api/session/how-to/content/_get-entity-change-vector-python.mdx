<Admonition type="note" title="">

* A [change vector](../../../../server/clustering/replication/change-vector.mdx) identifies a document version across the database group.  
  RavenDB updates the change vector whenever the document changes.

* When a session tracks a document loaded directly or returned by a query, it tracks both the entity and the document's change vector.
  If the session saves changes to the document, it updates the tracked change vector.  
    
* Use `session.advanced.get_change_vector_for()` to retrieve the tracked change vector.  
  The entity must be tracked by the session.

* In this article:
  * [Get entity change vector](../../../../client-api/session/how-to/get-entity-change-vector.mdx#get-entity-change-vector)
  * [Syntax](../../../../client-api/session/how-to/get-entity-change-vector.mdx#syntax)

</Admonition>

<Panel heading="Syntax">

<TabItem>
```python
def get_change_vector_for(self, entity: object) -> str: ...
```
</TabItem>

| Parameter  | Type     | Description                                            |
|------------|----------|--------------------------------------------------------|
| **entity** | `object` | A tracked entity whose change vector will be returned. |

| Return value | Description                                                                                                                                                       |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `str`        | The entity's tracked change vector, or `None` if the entity is new and has not yet been saved.<br/>Raises an exception if the `entity` is not tracked by the session. |
