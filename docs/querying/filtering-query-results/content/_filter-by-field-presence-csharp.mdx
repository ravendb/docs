<Admonition type="note" title="">

* Documents in the same collection can have different fields.  
  For example, a field added to newer documents might be missing from older documents.    
  You can optionally use [schema validation](../../../documents/schema-validation/overview.mdx) to require specific fields when documents are written.
    
* To filter documents by field presence:  
  * To find documents that **contain** a specified field, use `WhereExists`.  
  * To find documents that are **missing** a specified field, use `.Not.WhereExists`.  
  * Both are available through the [DocumentQuery API](../../../querying/document-query/what-is-document-query.mdx).  

* A field with an explicit `null` value counts as present.  
  For example, a document containing `"FirstName": null` matches `WhereExists("FirstName")`  
  and is excluded by `.Not.WhereExists("FirstName")`.    
    
* You can check field presence when querying a **static index** or when making a **dynamic query**.  
  When querying a static index, the check applies to the fields produced by the index's map function.

* In this article:
    * [Find documents that CONTAIN a field](#find-documents-that-contain-a-field)
        * [Dynamic query](#dynamic-query-existing-field)
        * [Static index query](#static-index-query-existing-field)
    * [Find documents that are MISSING a field](#find-documents-that-are-missing-a-field)
        * [Dynamic query](#dynamic-query-missing-field)
        * [Static index query](#static-index-query-missing-field)

</Admonition>

### Dynamic query {/* #dynamic-query-existing-field */}

* Use `WhereExists` to return documents that contain the specified field.  
  Documents that are missing the field are excluded from the results.

* RavenDB uses an auto-index to process the filter, creating one if needed.  
  Learn more in about this query type in [Query a collection - with filtering](../../../querying/overview.mdx#2-query-a-collection---with-filtering).

* You can check field presence using either a **field name** or a nested **field path**, as shown below.
    
---    

<ContentFrame>

#### Filter documents by field name

The following query returns employees whose documents contain the `FirstName` field:

<Tabs groupId='languageSyntax'>
<TabItem value="DocumentQuery" label="DocumentQuery">
```csharp
List<Employee> employees = session.Advanced
    .DocumentQuery<Employee>()
    .WhereExists("FirstName")
     // Or use a lambda expression: .WhereExists(e => e.FirstName)
    .ToList();
```
</TabItem>
<TabItem value="DocumentQuery_async" label="DocumentQuery_async">
```csharp
List<Employee> employees = await asyncSession.Advanced
    .AsyncDocumentQuery<Employee>()
    .WhereExists("FirstName")
     // Or use a lambda expression: .WhereExists(e => e.FirstName)
    .ToListAsync();
```
</TabItem>
<TabItem value="RQL" label="RQL">
```sql
from Employees
where exists("FirstName")
```
</TabItem>
</Tabs>

</ContentFrame>

### Static index query {/* #static-index-query-existing-field */}

* When querying a static index, use the **index-field name** in `WhereExists`.  
  The index must include the field whose presence you want to check.

* The following index maps:
  * `FirstName` to an index-field with the same name.
  * `Address.Location.Latitude` to an index-field named `Latitude`.    
  * The document ID to an index-field named `Id`, to retain entries for documents with missing fields.  
    See [Static index query for missing fields](#static-index-query-missing-field) for details.

    ```csharp
    public class Employees_ByFieldPresence
        : AbstractIndexCreationTask<Employee, Employees_ByFieldPresence.IndexEntry>
    {
        public class IndexEntry
        {
            // The index-fields
            public string Id { get; set; }
            public string FirstName { get; set; }
            public double Latitude { get; set; }
        }
    
        public Employees_ByFieldPresence()
        {
            Map = employees => from employee in employees
                select new IndexEntry
                {
                    // Include Id so documents with missing fields still have an index entry.
                    Id = employee.Id,
        
                    FirstName = employee.FirstName,
                    Latitude = employee.Address.Location.Latitude
                };
        }
    }
    ```

### Dynamic query {/* #dynamic-query-missing-field */}

* Use `.Not.WhereExists` to return documents that are missing the specified field.
* You can check for a missing field using either a **field name** or a nested **field path**, as shown below.

---
    
<ContentFrame>

#### Filter documents by field name

The following query returns employees whose documents do **not** contain the field `FirstName`:

<Tabs groupId='languageSyntax'>
<TabItem value="DocumentQuery" label="DocumentQuery">
```csharp
List<Employee> employeesWithoutFirstName = session.Advanced
    .DocumentQuery<Employee>()
    .Not.WhereExists("FirstName")
     // Or use a lambda expression: .Not.WhereExists(e => e.FirstName)
    .ToList();
```
</TabItem>
<TabItem value="DocumentQuery_async" label="DocumentQuery_async">
```csharp
List<Employee> employeesWithoutFirstName = await asyncSession.Advanced
    .AsyncDocumentQuery<Employee>()
    .Not.WhereExists("FirstName")
     // Or use a lambda expression: .Not.WhereExists(e => e.FirstName)
    .ToListAsync();
```
</TabItem>
<TabItem value="RQL" label="RQL">
```sql
from Employees
where true and not exists("FirstName")
```
</TabItem>
</Tabs>

In RQL, `not` cannot appear immediately after `where`.  
Use `where true and not exists(...)` when the missing-field condition is the first condition.  
_DocumentQuery_ adds `true and` automatically in this case.

</ContentFrame>

### Static index query {/* #static-index-query-missing-field */}

* Use `.Not.WhereExists` with the **index-field name**.  
  The field you want to check must be included in the index's map function.

* The index must also retain an entry for documents that are missing that field.
  The index used in this article maps the document ID to `Id`, ensuring that an entry is retained even when both `FirstName` and `Latitude` are missing.
   
* **Alternatively**, set [Indexing.IndexEmptyEntries](../../../server/configuration/indexing-configuration.mdx#indexingindexemptyentries) to `true` to retain entries for documents that are missing all mapped fields,
  without needing to map `Id` for this purpose.    

<Admonition type="note" title="">

If [Indexing.IndexMissingFieldsAsNull](../../../server/configuration/indexing-configuration.mdx#indexingindexmissingfieldsasnull) is `true`,
missing mapped fields are indexed as `null` and count as **present**.  
Consequently, `.Not.WhereExists` does not return documents whose missing fields were indexed this way.  
This setting does not affect auto-indexes.

</Admonition>

<Panel heading="Syntax">

### WhereExists

<Tabs groupId='languageSyntax'>
<TabItem value="DocumentQuery" label="DocumentQuery">
```csharp
IDocumentQuery<T> WhereExists(string fieldName);

IDocumentQuery<T> WhereExists<TValue>(Expression<Func<T, TValue>> propertySelector);
```
</TabItem>
<TabItem value="DocumentQuery_async" label="DocumentQuery_async">
```csharp
IAsyncDocumentQuery<T> WhereExists(string fieldName);

IAsyncDocumentQuery<T> WhereExists<TValue>(Expression<Func<T, TValue>> propertySelector);
```
</TabItem>
</Tabs>

| Parameter            | Type | Description |
|----------------------|------|-------------|
| **fieldName**        | `string` | For a dynamic query, the document field name or nested path.<br/>For a static index query, the index field name. |
| **propertySelector** | `Expression<Func<T, TValue>>` | A lambda expression that selects the field. For static index queries, the resulting field name must match a field in the index. |

---
    
### Not

The `Not` property negates the next filtering condition.  
Place it immediately before `WhereExists` to search for missing fields:

```csharp
.Not.WhereExists("FirstName")
```

---
    
### RQL

```sql
// Find documents with the field.
where exists("FieldName")

// Find documents without the field.
where true and not exists("FieldName")
```
