### Increment counter

Use `incrementCounter` to add a value to a counter.  
If the counter does not exist, RavenDB creates it with the supplied value.

<Tabs groupId='languageSyntax'>
<TabItem value="Session_defer_syntax" label="Session_defer_syntax">
```java
// Add 20 to Likes on orders/1-A.
// If Likes does not exist, RavenDB creates it with the value 20.
PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("incrementCounter(this, args.name, args.value);");

Map<String, Object> values = new HashMap<>();
values.put("name", "Likes");
values.put("value", 20);
patchRequest.setValues(values);

session.advanced().defer(new PatchCommandData(
    "orders/1-A",  // id
    null,          // changeVector
    patchRequest,  // patch
    null));        // patchIfMissing

session.saveChanges();
```
</TabItem>
<TabItem value="Operations_syntax" label="Operations_syntax">
```java
// Add 20 to Likes on orders/1-A.
// If Likes does not exist, RavenDB creates it with the value 20.
PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("incrementCounter(this, args.name, args.value);");

Map<String, Object> values = new HashMap<>();
values.put("name", "Likes");
values.put("value", 20);
patchRequest.setValues(values);

store.operations().send(new PatchOperation(
    "orders/1-A",   // id
    null,           // changeVector
    patchRequest)); // patch
```
</TabItem>
</Tabs>

<Admonition type="note" title="">

`incrementCounter` accepts either a document ID or a document object in the patch script.  
Omit the value to increment by `1`; pass a negative value to decrement the counter.

</Admonition>

### Get counter

Use `counter` to read a counter value while a patch script is running.  
The following example stores the current `Likes` value in a regular document field named `LikesSnapshot`.

<Tabs groupId='languageSyntax'>
<TabItem value="Session_defer_syntax" label="Session_defer_syntax">
```java
// Read Likes from orders/1-A and store its current value in LikesSnapshot.
PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("this.LikesSnapshot = counter(this, args.name);");
patchRequest.setValues(Collections.singletonMap("name", "Likes"));

session.advanced().defer(new PatchCommandData(
    "orders/1-A",  // id
    null,          // changeVector
    patchRequest,  // patch
    null));        // patchIfMissing

session.saveChanges();
```
</TabItem>
<TabItem value="Operations_syntax" label="Operations_syntax">
```java

    "orders/1-A",   // id
    null,           // changeVector
    patchRequest)); // patch
```
</TabItem>
</Tabs>

<Admonition type="note" title="">

`counter` accepts either a document ID or a document object in the patch script.  
It returns `null` if the specified counter does not exist.

### Append time series entry

Use `timeseries(...).append` to append an entry to a time series.

<Tabs groupId='languageSyntax'>
<TabItem value="Session_defer_syntax" label="Session_defer_syntax">
```java
// Append a one-value HeartRates entry to users/1-A.
// RavenDB treats timestamps passed to patch scripts as UTC.
PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("timeseries(this, args.name).append(new Date(args.timestamp), args.values, args.tag);");

Map<String, Object> values = new HashMap<>();
values.put("name", "HeartRates");
values.put("timestamp", new Date());
// Pass an array instead when the entry contains multiple values.
values.put("values", 78);
values.put("tag", "watches/fitbit");
patchRequest.setValues(values);

session.advanced().defer(new PatchCommandData(
    "users/1-A",   // id
    null,          // changeVector
    patchRequest,  // patch
    null));        // patchIfMissing

session.saveChanges();
```
</TabItem>
<TabItem value="Operations_syntax" label="Operations_syntax">

<Admonition type="note" title="">

Provide the entry's timestamp, one numeric value or an array of numeric values, and an optional tag.  
Learn more about appending time series entries via patching in [Patch time series entries](../../../../../document-extensions/timeseries/client-api/session/patch.mdx#append-multiple-entries),  
and see the available time series patch methods in [Time series: JavaScript support](../../../../../document-extensions/timeseries/client-api/javascript-support.mdx).

### Delete time series entries

Use `timeseries(...).delete` to delete a range of time series entries.

<Tabs groupId='languageSyntax'>
<TabItem value="Session_defer_syntax" label="Session_defer_syntax">
```java
// Delete HeartRates entries from the last hour, including both boundaries.
Date to = new Date();
Date from = DateUtils.addHours(to, -1);

PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("timeseries(this, args.name).delete(args.from, args.to);");

Map<String, Object> values = new HashMap<>();
values.put("name", "HeartRates");
values.put("from", from);
values.put("to", to);
patchRequest.setValues(values);

session.advanced().defer(new PatchCommandData(
    "users/1-A",   // id
    null,          // changeVector
    patchRequest,  // patch
    null));        // patchIfMissing

session.saveChanges();
```

</TabItem>

### Copy attachment

Use `attachments(...).copyFrom` to copy an attachment from a source document to the document being patched.  
The copy is performed entirely on the server, without downloading and re-uploading the attachment through the client.

<Tabs groupId='languageSyntax'>
<TabItem value="Session_defer_syntax" label="Session_defer_syntax">
```java
// Copy orders/2-A/invoice.pdf to orders/1-A as invoice-copy.pdf.
PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("attachments(this, args.targetName).copyFrom(args.sourceDocId, args.sourceName);");

Map<String, Object> values = new HashMap<>();
values.put("sourceDocId", "orders/2-A");
values.put("sourceName", "invoice.pdf");
values.put("targetName", "invoice-copy.pdf");
patchRequest.setValues(values);

session.advanced().defer(new PatchCommandData(
    "orders/1-A",  // id
    null,          // changeVector
    patchRequest,  // patch
    null));        // patchIfMissing

session.saveChanges();
```
</TabItem>
<TabItem value="Operations_syntax" label="Operations_syntax">
```java
// Copy orders/2-A/invoice.pdf to orders/1-A as invoice-copy.pdf.
PatchRequest patchRequest = new PatchRequest();
```

</TabItem>

<Admonition type="note" title="">

The `copyFrom` method returns `true` on success and `false` if the source document, target document, or source attachment was not found.

Learn more about copying attachments in [Copy attachments - via patching](../../../../../document-extensions/attachments/copy-move-rename.mdx#copy-attachments---via-patching),  
and see the full patch method syntax in [JavaScript engine - Attachment operations](../../../../../server/kb/javascript-engine.mdx#attachment-operations).

### Mark attachment as remote

Use `attachments(...).remote` to schedule an existing local attachment for upload to a configured remote storage destination.  
Provide the attachment name, destination identifier, and scheduled upload time.

<Tabs groupId='languageSyntax'>
<TabItem value="Session_defer_syntax" label="Session_defer_syntax">
```java
// Schedule orders/1-A/invoice.pdf for remote upload in one day.
PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("attachments(this, args.name).remote(args.identifier, args.at);");

Map<String, Object> values = new HashMap<>();
values.put("name", "invoice.pdf");
// Must match a configured remote destination identifier.
values.put("identifier", "my-amazon-storage");
values.put("at", DateUtils.addDays(new Date(), 1));
patchRequest.setValues(values);

session.advanced().defer(new PatchCommandData(
    "orders/1-A",  // id
    null,          // changeVector
    patchRequest,  // patch
    null));        // patchIfMissing

session.saveChanges();
```
</TabItem>
<TabItem value="Operations_syntax" label="Operations_syntax">
```java
// Schedule orders/1-A/invoice.pdf for remote upload in one day.
PatchRequest patchRequest = new PatchRequest();
patchRequest.setScript("attachments(this, args.name).remote(args.identifier, args.at);");

```
</TabItem>
</Tabs>

<Admonition type="note" title="">

This schedules the attachment for remote upload; it does not upload the attachment immediately.  
If the Remote Attachments feature and the selected destination are enabled, a background task uploads the attachment during a scan after the scheduled time has passed.

Learn more in [Schedule existing attachments for remote upload](../../../../../document-extensions/attachments/store-attachments/store-attachments-remote.mdx#schedule-existing-attachments-for-remote-upload),  
and see how to define destinations in [Configure remote attachments](../../../../../document-extensions/attachments/configure-remote-attachments.mdx).

</Admonition>
